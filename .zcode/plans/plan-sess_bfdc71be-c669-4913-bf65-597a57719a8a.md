Add padding to `.icon-picker-wrap` in `src/lib/client/components/CategoryModal.svelte` (line 376) so the selected icon's scale + box-shadow ring isn't clipped by the scroll container:

```css
.icon-picker-wrap {
	overflow-x: auto;
	margin-bottom: 16px;
	padding: 8px 8px 12px; /* replaces padding-bottom: 4px */
	-webkit-overflow-scrolling: touch;
}
```

- 8px top/sides gives clearance for the ~5px overflow from the selected state (scale 1.1 + 3px ring), including icons at the left/right scroll edges.
- 12px bottom keeps extra room for the scrollbar (the original 4px was for that purpose).
- No other rules or media queries touch this class, so this single change covers desktop and mobile.
